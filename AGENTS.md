# Research workflow

- The current workflow is scan, upload logs, analyze evidence, then wait for an explicit instruction before processing an infected computer.
- Do not run real cleanup, repair, quarantine, process termination, persistence removal, or document recovery merely to verify a change. Use inert fixtures and read-only diagnostics.
- Preserve the user's research samples, including samples on removable media. Do not execute them.
- Keep scan and processing reports independently, with operation type, status, session ID, operation ID and the corresponding journal. Processing must not overwrite pre-processing evidence.
- Source commits and public releases must exclude real samples, user documents, collected reports, device enrollment files, credentials, keys and device-specific protection settings.
