# WormRecovery 1.8.10

修复已分析的PNG尾随编码载荷漏检。

- 根据文件内容检查PNG尾部的载荷偏移和编码种子，预检最多读取81字节并恢复文件位置，只对PE形状候选完整解码。
- PNG候选静态上限为8MiB，覆盖本次约5MiB载荷；其他格式和旧RC4预算不变，超过预算保留待核。
- 已静态证实远程注入和清日志代码的完整载荷指纹标记为确认恶意。已知打包配套载荷和加载DLL单独标记为已识别待核；改名、扩展名、PNG元数据不参与恶意判定。
- 未知尾随PE、截断、异常结构不自动确认为恶意。正常图片、同名无害文件、通用API字符串以及嵌入样本的普通父PE不继承恶意身份；签名宿主不因同目录关系自动报毒。
- 扫描不执行样本、不实际清理；处理仍需用户主动发起，沿用1.8.9不备份方式。

检测范围限于已知内容指纹和该载体格式，不代表可识别任意重编译变种。

已验证：475项无害回归通过（116.513秒），其中15项为新增边界测试。原目录8文件的源码只读检查得到2个确认恶意载体、4个已识别配套待核项，2个签名宿主不单独报毒，原文件哈希不变。
