# WormRecovery 1.8.3

大型程序和脚本原先受内存字节解析上限影响，即使没有检测到恶意内容，也会直接进入待核查。文件较多的电脑因此可能出现大量无效复核和重复引擎工作。

本版对超过 16 MiB 的 PE 程序和超过 4 MiB 的脚本使用完整文件规则扫描。PE 同时通过只读内存映射核对结构、特征位置及外层代码归属，避免把完整大文件复制到 Python 内存。只有成功完成检查且源身份稳定，才记录“已完成已知规则检查、未命中”；超时、映射失败、已知壳解码未完成或文件变化仍保留明确的未完成结果。

- 单文件完整检查上限为 2 GiB；扫描时间按文件大小给出有界预算，最多 180 秒，兼顾机械硬盘读取速度。物理磁盘并发限制继续生效。
- 检查开始和结束时核对文件句柄与路径的身份、大小及时间。Windows 的 `stat/fstat` 时间语义分别比较，避免误报变化。
- 报告分别记录完整扫描文件数、实际规则覆盖字节数及未完成项目，不把字节数当成文件数。
- 完成规则扫描后主动释放 YARA-X 保留的文件映射，避免扫描器自身阻止后续恢复或重命名。
- 可提取的大型程序原件也使用同样的完整规则与结构复核，检查未完成时保留源文件。

内容确认、嵌入宿主保护、Office 结构化恢复、签名更新与缓存启动等 1.8.2 功能保留。完整文件扫描仍是已知家族规则的覆盖说明，不代表能识别全部未知恶意软件或自动还原任意保护壳。
