# 1.7.3

- 管理员只读检测在普通读取遭到拒绝后，使用已启用的 SeBackupPrivilege 和 FILE_FLAG_BACKUP_SEMANTICS 重试。句柄仅请求读取权限并允许其他进程共享访问；不修改文件 ACL，不结束应用程序。
- 超长本地及 UNC 路径转换为显式扩展路径，避免读取阶段的传统路径长度限制。摘要、PE 检测、脚本和 Office 容器读取、二次分析副本使用统一读取入口。
- 不依据 _MEI、Chrome 或 Firefox 等目录名称跳过内容检测。重试失败保持异常，不改成安全结论。
- 活动分页文件和交换文件仍会显示在线读取限制；不通过禁用虚拟内存、结束系统进程或隐藏错误消除提示。
- 报告新增实际引擎文件检查计数、二次分析候选数和调用状态。版本清单只说明组件可用，不能证明已调用。没有未决候选文件时明确记录未调用二次引擎。
- REA 当前集成为静态 PE 导入分析，未内置 Ghidra 深度反编译。无规则命中不等同于证明文件安全。
- 修正已经由宏源码和编译指令确认感染的文档仍显示“尚未确认”的说明文字。

验证采用无害样例、回归测试和只读复查。真实诊断报告与样本不随源码或发行包发布。扫描与处理日志继续分别保存；本次更新不自动执行感染处理。
