# 1.7.8

- 内部分析组件改为目录运行形式，封装在单一客户端 EXE 内；用户仍只需复制一个 WormRecovery.exe。
- 宏分析直接调用内部分析组件，不再重复启动完整 CLI 或逐份解压分析 EXE。不同组件之间重置打包运行时状态。
- 旧版 Office 文件使用备份读取语义和只读私有副本分析，避免分析进程直接打开受限原件。原件内容和访问权限保持不变。
- 先检查子进程退出状态，再解析 JSON；保留启动失败、空输出及资源隔离失败的具体原因。
- 保留自动日志上传、历史报告补传、内网优先与外网备用、匹配接收凭据和 IDV 磁盘识别兼容处理，无需登记或导入配置。
- 不根据文件名、安装目录或未检出结果直接删除宏，也不将解析失败当作已确认感染。

验证使用只读组件和惰性文档。具体 IDV 驱动及进程策略仍以对应电脑的复测日志为准。

验证结果：261 项回归测试通过；单文件发行版通过 22 项检查；6 个选定的正常 VBA 项目经 36 次并发工作进程调用均返回有效结果，随后以单文件发行版扫描 12 份私有 OOXML/OLE 测试容器，无解析错误且内容未变。诊断回传通过 13 项检查，覆盖免配置提交、扫描与处理报告补传、重复提交去重及接收凭据保存。更新替换校验通过，并确认无效签名不会覆盖现有程序。上述测试不执行宏，诊断测试仅使用本机回环地址与惰性报告。
