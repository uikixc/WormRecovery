# WormRecovery 1.5.0

发布日期：2026-11-05。

## 版本检查与安装

- 发行版启动后在后台读取本仓库最新正式 GitHub Release；过滤草稿和预发布版本，按主、次、修订版本数字比较。
- 侧栏新增“检查更新”和“更新设置”。发现新版后确认下载，验证后确认安装，安装前等待当前扫描或修复结束。
- 更新程序由单文件中的内部组件按需运行。旧实例退出后在原路径替换，并保留旧版备份；替换、校验及重新启动失败时执行回滚。
- 离线或更新授权失败不会阻止扫描。更新下载与版本检查不占用扫描的磁盘并发配额。

## 下载线路

公共附件可使用 GitHub 直连、GH-Proxy、GHFast、GHProxy.net，下载前并发执行有界短传输测试，优先选择当前测试较快的线路，失败后回退其他线路。

当前仓库为私有仓库。私有附件只通过 GitHub API 授权下载，不向公共代理泄露令牌、私有下载地址或 GitHub 临时签名地址。每台设备在“更新设置”保存仅限本仓库、Contents 只读权限的细粒度访问令牌。

## 完整性与凭据

- 更新清单采用 Ed25519 签名，程序内置公钥；校验版本、来源仓库、平台、文件长度和 SHA-256。
- 仅接受 HTTPS 和允许的跳转主机，跨主机跳转去除授权头。拒绝错误签名、损坏文件、不匹配的附件地址和超出清单长度的下载。
- 私钥以 Windows DPAPI 加密后保存在源码之外，访问令牌保存在当前 Windows 用户凭据管理器。发布校验不是 Windows Authenticode 签名。
- 更换程序前核对旧程序哈希，拒绝重解析点目标和覆盖已有备份；失败的部分下载不会作为可安装文件使用。

## 验证范围

测试覆盖签名篡改、版本比较、私有凭据路由、跨主机去除授权、下载损坏或取消、旧文件变化及替换失败回滚。另验证实际发行版的宏分析和离线引擎，以及内部更新执行组件的原位替换。具体运行结果保存在本地构建证据目录，不随源码上传。

旧版本没有更新功能，需要手动替换一次主程序。第一次发布即为 v1.5.0；以后新增版本应先完成构建、测试、签名及草稿附件核对，再公开为正式 Release。仓库继续保持私有。
