# WormRecovery 1.8.5

本版针对重复复核、异常累计计数和安装器恢复被结构解析拒绝的问题。内容规则版本为 2026.11.07.1。

- 同一扫描及修复会话内，相同完整 SHA-256、引擎清单、规则版本与分析任务的已完成结果可以复用。每个当前文件仍重新复制并完整核对内容；内容、规则、引擎或深度选项改变即重新分析。失败、超时、取消与部分覆盖结果不复用。Office 当前解析和最终判定仍重新计算，未确认文件不会因缓存变成安全文件。
- 常规检测继续执行病毒库、内容规则和适用的静态结构检查。capa 能力标签分析移为显式深度选项，默认关闭，可在界面勾选或使用 --deep-analysis。报告明确标记未选择，不能称所有引擎都已执行。
- 同一路径、相同错误、相同处理类型合并为一项，保留发生次数、初扫/复核/修复阶段与逐次日志。界面分别显示修复失败、检查受限和确认残留；读取失败仍是未完成检查。
- 修正只有只读非执行数据节别名重叠时拒绝整个 PE 的问题，记录别名范围。涉及执行代码、可写数据或代码归属不明的重叠继续拒绝；小 PE 结构解析失败也明确保留未完成状态。
- 恢复受阻报告包含提取层数、提取内容哈希、检查状态和具体原因，区分恶意代码检出、已识别但未建立恢复依据、解析未完成。

验证使用无害合成文件和只读静态检查，未执行病毒样本，未在真实电脑上实施清理。全盘文件遍历仍需要时间；本版不承诺全部恶意家族识别、全部位置可读或一轮彻底清理。TSCO 内容组合及改名边界的既有测试继续保留。

本版验证：437 项自动测试通过。实际成品以只读模式检查 3 个测试文件，改名 TSCO 内容保持 identified / review_binary，无害只读节别名文件未误报，检查异常为 0，原始样本和测试副本哈希均未改变。该小范围检查用时约 39 秒，其中二次分析约 14 秒；此结果不代表全盘扫描耗时。两份实际受阻安装器的提取原件已通过只读结构检查，尚未在目标电脑实际恢复，仍需用户更新后复测。
