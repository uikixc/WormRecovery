# WormRecovery 1.6.0

发布日期：2026-11-05。

## 离线自动判定

新增内置的证据判定模块，扫描期间直接调用，不需要 Codex、聊天服务、在线模型或操作人员为每台电脑逐文件下结论。报告记录规则版本、分类、依据及判断范围。

- 普通本地图片引用：要求当前文档无宏、Office 结构解析完成、引用为限定类型的本地路径、ClamAV 检查完成且 YARA-X 未命中；满足时归入说明项，保留文件，不删除引用。远程地址、网络共享、程序伪装图片、地址截断及其他活动内容不会由该规则放行。
- 外部工作簿数据链接：读取 externalBook、ddeLink、oleLink 的具体类型并按所属成员关联。只对满足条件的本地普通工作簿链接自动归类；DDE/OLE、远程模板和未知内容保持独立风险状态，不执行外部目标。
- 异盘 Office 组件：允许识别挂载在其他盘符的安装目录，仍必须同时匹配目录结构、文件名和已核对的完整文件 SHA-256；不添加针对用户报告的文件名白名单。
- VBA 行为组合：分析自动入口、下载与执行、自我复制、持久化等组合，支持受限 Chr/ChrW 整数常量和字面量拼接，不执行 VBA。组合命中明确显示高风险行为；未命中不代表未知宏安全，也不据此删除整份文档。
- 大型 Word XML 使用有界流式解析，继续检查 DDE 和异常 XML 声明。空文件、RTF 改扩展名、未知格式分别给出原因；不能从空文件恢复缺失的正文。
- 旧版 OLE Office 文件的宏进入隔离的源码及编译指令解析流程。

## 版本检查修复

此前下载器有备用线路，但检查版本仍依赖 GitHub API。新版在公开仓库 API 不可达时并发尝试 GitHub 发布附件直连和三条公共代理，读取并验证 Ed25519 签名清单；未通过签名验证的内容不能作为更新。

错误提示区分连接超时、DNS、TLS/证书、HTTP 和清单格式，失败不会影响离线扫描。私有仓库已确认不可用时不转发私有下载；备用公共线路不携带任何访问令牌。

## 验证与范围

测试包含普通资源与危险链接区分、全部关系目标保留、异盘组件内容变化、宏行为组合、超过 8 MiB 的 Word 正文检查、API 故障回退和签名拒绝。发行版另验证独立 EXE 内的自动分类和真实离线引擎。

软件仍可能对加密、损坏、未支持结构和未知活动内容给出未完成或未解决结论。这些状态保留明确原因与原件，不通过把全部未检出文件标为安全来消除提示。病毒库未命中不能单独证明无病毒。
