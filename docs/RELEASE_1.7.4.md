# 1.7.4

- 主界面新增“检测日志服务器”，诊断反馈窗口新增“检测服务器连接”。后台分别检查内网、外网服务及上传授权，显示线路、耗时和失败原因；检测不上传文件，也不改变已有待提交队列。
- 接收服务提供只读上传授权检测端点。服务可达与上传授权通过分别显示，未导入配置不会显示“可上传”。旧服务无授权检测端点时明确提示兼容性状态。

- 修正没有待提交队列、没有发送报告时仍显示“诊断资料已提交”的错误。空队列明确显示“本次未发送报告”，不作为当前扫描已回传的证明。
- 提交成功必须有匹配的服务器接收编号；状态保存接收编号、服务器地址、接收时间及本次成功份数。连接失败继续保留压缩报告，并显示尝试地址及失败类型。
- 诊断反馈初始界面显示最近提交状态，不再仅凭“已启用、待提交零份”推断已经上传。
- 接收服务新增 receiver-requests.jsonl，记录请求时间、来源地址、HTTP 状态和接收编号；不记录授权头、文档正文、诊断正文或原始请求 URL。
- 请求记录超过 2 MiB 后轮换为一份历史记录。现有服务配置、设备授权和已收报告保留。

客户端按版本放入独立发行目录。升级接收服务只替换服务程序，不修改已收报告和设备授权。
