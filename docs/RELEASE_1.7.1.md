# WormRecovery 1.7.1

- 诊断收集改为 HTTP + gzip 压缩上传，不使用 TLS、端到端加密封套或 Base64 包装。
- 默认地址为 http://10.205.103.120:10888，失败后尝试 http://8.134.112.170:10888。接收服务可与客户端运行在同一台 Windows 电脑。
- 保留后台上传、断网压缩队列、上传授权、接收凭据、报告去重、内容大小限制、字段脱敏和原件不上传。
- 提供 migrate-http 命令，保留旧配置备份并迁移设备授权。客户端必须导入新版设备配置；旧加密队列需从保留报告重新提交。
- 文件扫描、离线分析、恢复流程和更新包签名校验保持原有逻辑。

HTTP 上传内容未加密。1.7.0 的原有配置不能直接用于本版；服务与客户端应配套升级。详细步骤见 DIAGNOSTIC_COLLECTION.md。

验证：198 项回归测试通过；成品命令行客户端和接收程序完成 HTTP 收件、脱敏、哈希依据保留、凭据保护、暂停和汇总测试。本机部署验证覆盖 127.0.0.1 与 10.205.103.120 的服务响应，以及实际扫描报告提交。公网连通性不能由本机或内网测试替代。
