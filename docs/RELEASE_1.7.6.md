# 1.7.6

- 修复逐磁盘调用 Get-Partition 时，单个设备没有分区即中断整个扫描准备过程的问题。分区改为一次性枚举。
- 使用 Windows 原生挂载卷、磁盘区段和存储总线信息交叉校验磁盘接口返回结果。主接口失败、返回空结果或遗漏盘符时，自动回退到 Win32 设备关联及原生卷映射。
- 为原生接口明确识别的虚拟卷增加独立识别路径。无法确认的卷记录明确故障，不以扫描成功或零风险代替。
- 保留可移动设备的物理设备归组、所有分区盘符选择、本机排除设备和卷标识校验。
- PowerShell 进度输出默认关闭；错误界面解析错误流，不再显示原始 CLIXML 进度数据。
- 扫描准备阶段失败也会独立保存 report.json 与 journal.jsonl，操作标注为失败、扫描文件数为零；导入采集配置后自动进入诊断提交队列。
- 日志外网地址继续使用 8.134.112.170:35981，内网地址继续使用 10.205.103.120:10888。

验证范围：本机只读磁盘识别、强制兼容回退、模拟分区接口异常及缺失数据、可移动设备分区归组和排除策略、诊断故障采集及全套回归测试。联想云 IDV 的具体驱动组合仍需在对应实机复测；本次验证不执行感染处理或研究样本。
