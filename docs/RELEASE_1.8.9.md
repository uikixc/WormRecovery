# WormRecovery 1.8.9

按用户要求取消感染文件备份，取代1.8.8的同卷保留原件方案。

- 程序及同扩展名文档修复：Windows ReplaceFileW不传备份路径，成功后仅留下恢复文件。
- 已确认恶意载荷、脚本、快捷方式及组件：复核通过后直接删除，不复制、不移动至隔离目录。
- 扩展名变化的文档：先生成并校验恢复文件，目标冲突时不覆盖；恢复文件提交成功并再次验证后删除感染源。删除失败保留源并报告失败，不声称处理完成。
- 保留必要的文件哈希、操作日志和关联判定结果，不保存文件内容副本；已处理配套组件不再依赖隔离副本才能确认后续关联运行时。
- 界面明确说明不创建文件备份，成功后无法由工具撤销。处理前完整内容复核、恢复文件验证及受保护范围仍生效。
- 不自动删除旧版留下的备份、隔离目录、用户研究样本。软件自身更新失败回退不属于感染文件处理流程。

本轮仅用无害临时文件测试修复和删除。未执行病毒样本，未对感染电脑进行实际清理。

验证结果：460 项回归通过（51.301 秒），覆盖真实 Windows 无备份替换、权限保留、直接删除失败、源文件变化、硬链接拒绝以及文档目标冲突。20 GiB 无害稀疏文件测试确认不产生备份，该项模拟哈希，不代表真实 20 GiB 读写或恢复速度。测试仍有既有 Tk 退出提示。

实际 1.8.9 成品只读扫描 4 个文件：两种改名或扩展名的 TSCO 内容均识别为待核查，两个无害边界文件无命中；检查异常为 0，补充引擎未调用，样本及扫描副本哈希不变。总耗时 34.218 秒，文件扫描阶段 0.313 秒；不代表启动或全盘扫描性能。其他电脑更新和真实处理仍需用户实测。
