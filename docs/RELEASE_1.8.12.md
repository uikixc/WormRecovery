# WormRecovery 1.8.12

把已核实的两处部署内容和 R9 局部代码证据接入常规离线检测，补齐完整哈希之外的识别边界。规则版本：2026.11.12.1。

- 对已知载荷与配套 DLL 增加规范化外层 PE 映像指纹。只忽略 COFF 时间戳、PE 校验和及映像之外的附加数据；其余头部、入口、目录、节布局、代码及数据仍须完整匹配。文件改名、这些元数据变化或尾部添加数据后仍可识别。每次命中记录实际文件 SHA-256、参考身份及忽略范围。
- 将 R9 已核对的入口和三个分离代码位置组成有限内容规则。入口和四段特征必须位于外层 PE 的可执行节；内容变化但组合仍存在时列为待核。这种有限组合不进入精确关联组，也不自动获得删除权限。
- 已确认注入载荷保持确认检测；打包图片、打包 DLL 与签名宿主继续按既有证据和关联组审核。通用 API 名称、随机目录名及单个特征不会升级为病毒。
- PNG 尾随数据解码改用等价的分段字节变换，减少 Python 逐字节循环。常规扫描继续不启动补充引擎；未知项仍明确保留。
- 沿用无备份处理及关联组逐项授权。此次只修改、测试和发布程序，没有对感染电脑进行实际清理。

P0-03 首层消费者与完整消费链、五回调职责、部署实际运行上下文仍未完成。现有 TSCO 有限内容规则继续保留，不据 R9 新增挖矿或文档蠕虫归属结论。此版本不声称覆盖重编译、全新代码变种或全部病毒。
