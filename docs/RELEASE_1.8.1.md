# 1.8.1

修复候选文件较多时，ClamAV 在整批 180 秒期限到达后丢弃已经完成的文件结果，导致所有候选同时显示“分析未完成”的问题。现在按独立文件保存结果和进展，单文件资源限制与整批期限分别计算。批次中断后，已经检出的威胁和已经完成的检查均保留；只对未完成项重试一次。相同字节及扩展名的校验副本共享结果，正常批次仍只加载一次病毒库。

- 界面显示病毒库加载、当前文件和已返回结果数量；文件长时间没有进展时终止本软件拥有的分析进程并记录原因。零字节文档独立报告正文缺失，不再因其他文件超时而失去这一结论。
- 读取 Windows 实际文件属性和重解析标签，区分云盘过滤目录、普通目录、符号链接和目录联接。过滤目录按原入口正常遍历和读取，不再对它强行查询链接目标。读取仍失败时保留实际错误；失效的历史链接单独标为目标缺失。
- 根据完整字节结构识别 AppleDouble 元数据附属文件与回收站索引，验证项范围、长度、重复记录和路径结构，不打开记录中的目标路径。仅文件名相似不能触发正面结论；非空资源叉继续保留未核验状态。
- 新增嵌入对象检查：逐项记录类型、字节数、SHA-256、OLE 流、嵌套关系和内容规则结果；解析受限的无宏 OOXML、BIFF8 工作簿及 OLE 原生包装。目录项不再当成对象文件。宏、程序、外部活动关系、未知对象及超限结构继续保留，公式二进制对象只报告实际识别范围。
- VBA 源码与编译缓存分开分析。只对确有缓存的模块解码；项目缺少缓存标识符表时，仍保留已提取源码、行为判断和内容规则结果，并说明缓存覆盖不足。不会用源码检查成功替代缓存认证，也不会因其他引擎未完成而覆盖已发现的家族宏证据。
- 报告补齐文件大小、遍历耗时和复核耗时；详细信息显示每个未完成引擎的原因及嵌入对象检查结果。
- 保持一个 EXE、离线检测、自动回传和独立扫描/处理报告。打包验证检查实际发行程序中嵌入对象解析能力是否可调用。

验证结果：319 项回归测试通过，其中包含进程中断后保留逐文件结果、只重试未完成输入和检出优先于资源限制的故障注入检查；实际单文件程序通过 22 项运行检查。96 份生成文档通过 36 项分类与批量检查，包含 73 份独立纯文本候选及一份相同副本，全部取得独立病毒库结果、进度和去重依据；无宏嵌入文档自动分类，未知公式、嵌套宏、资源叉、缺失缓存表和两份故意构造的无效格式均按实际证据保留。36 次独立 Office 分析调用成功，另有 12 份私有测试容器复用工作进程且解析错误为 0；自动回传通过 13 项本机回环检查；签名更新替换、旧文件保留和无效签名拒绝均通过。测试结果仅描述上述覆盖，目标设备结果需复扫取得。

本版修复软件自身的结果丢失、结构误判和解析覆盖问题。没有真实文件字节的历史日志不能用于重新认证其中的全部对象；新版需要在目标设备只读复扫取得逐文件结果。未确认的宏、资源叉和公式对象仍保留原件。此次验证不执行文档或宏，不清理实际感染文件，不上传测试文档至生产收集服务。
