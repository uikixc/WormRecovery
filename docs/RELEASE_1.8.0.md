# 1.8.0

本版补充离线文档判定能力，减少已解析内容仍被统一列为未知宏的情况。

- 按完整字节内容识别误用 `.doc` 扩展名的纯文本，不以文件名或软件安装目录作为判断依据。二进制、HTML/XML/RTF、未闭合标记及解码异常不使用此规则。
- 分别核验 VBA 模块声明、全部提取源码、模块源码偏移、项目缓存、SRP 缓存及其他 OLE 流。仅当所有模块均为空实现、缓存不存在、没有未核验的项目或库引用且容器检查完整时自动归类；不会把“未返回编译指令”单独视为安全。正面结论重新绑定至其他引擎使用的同一份 SHA-256 校验副本。
- 旧版 Excel 的正面规则另需 BIFF8 工作表目录和完整子流一致。只允许已分类的数据与格式记录；公式、名称、外部连接、对象、未知记录和异常子流均阻止自动归类。
- 无宏文档中的受限 `cid:image.jpg@id` 图片内容 ID 引用可自动归类。外部模板、网络图片、嵌入对象、宏和截断目标仍需独立检查。
- 零字节文档明确标为“正文缺失”，保留恢复历史原件或备份的建议。空文件没有可供病毒库检查的内容，不再误写成宏解析错误，也不表示正文已恢复。
- 修复诊断脱敏规则误删 VBA 源码分析引擎计数的问题。报告保留调用数量和结构证据，仍不采集文档正文或 VBA 源码。
- 保持单 EXE、离线运行、免配置自动回传与独立的扫描/处理报告。此版本不自动清理尚未确认的文件。

验证使用源码生成的无害 CFB、MS-OVBA、BIFF8 和 OOXML 容器，并检查打包后的单文件程序。未知缓存、孤立模块、非空代码、伪造纯文本、外部模板与损坏结构均有反例检查。验证不执行宏，不处理实际感染样本，不将测试文档回传生产服务器。

验证结果：289 项回归测试通过；单文件运行通过 22 项检查；新增文档分类通过 19 项检查；36 次独立 Office 分析调用成功，12 份私有测试容器复用工作进程且解析错误为 0；日志回传通过 13 项本机回环检查；签名更新替换和无效签名拒绝均通过。上述结果仅描述测试覆盖，不替代目标电脑复测。

旧报告没有完整模块与缓存清单时，不能据此补认空宏项目。相关设备需要使用新版进行一次只读扫描，才能取得该规则需要的证据。本版不承诺将任意未知宏认定为安全或对未验证的感染结构执行恢复。

规则依据：[MS-OVBA MODULEOFFSET](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-ovba/2d3f4cb1-8945-4d6a-9c53-bd38e197e131)、[项目缓存流](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-ovba/ef7087ac-3974-4452-aab2-7dba2214d239)、[RFC 2392](https://www.rfc-editor.org/rfc/rfc2392.html)。这些规范说明文件结构，不单独证明某一实际文件安全。
